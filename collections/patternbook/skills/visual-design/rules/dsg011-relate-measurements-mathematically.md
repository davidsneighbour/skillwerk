---
id: DSG011
title: Relate measurements mathematically
applies-when: Choosing spacing, sizing, or dimension values.
---

## Rule

Spacing and element dimensions should derive from a consistent scale.

## Check

* Prefer a spacing and sizing scale over arbitrary pixel values.
* Components should normally use multiples or steps from the same system.
* Grids should align significant dimensions where practical.
