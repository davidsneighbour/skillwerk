---
id: DSG012
title: Order sequential elements by visual weight
applies-when: Arranging a row or column of elements with different visual weights, such as button groups.
---

## Rule

When elements form a row or column, arrange them in a coherent progression from visually heavy to visually light.

## Check

* Put the visually heaviest element at the outside edge of the group.
* Progress towards lighter elements rather than alternating visual weights arbitrarily.
