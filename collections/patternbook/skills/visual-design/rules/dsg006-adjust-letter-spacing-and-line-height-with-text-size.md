---
id: DSG006
title: Adjust letter spacing and line height with text size
applies-when: Setting letter spacing or line height for text at any size.
---

## Rule

As type gets larger, letter spacing and line height can generally tighten. As type gets smaller, they generally need more room.

## Check

* Large display type should not inherit body-text tracking and leading mechanically.
* Small text should not use excessively tight tracking or line height.
