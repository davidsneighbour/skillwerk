---
id: DSG016
title: Set drop-shadow blur to twice its distance
applies-when: Defining a drop shadow.
---

## Rule

For conventional soft drop shadows, use a blur radius approximately twice the shadow's offset distance.

## Check

* Example: a 4px vertical offset should use about 8px blur.
* As apparent elevation increases, consider reducing shadow opacity while increasing softness.
