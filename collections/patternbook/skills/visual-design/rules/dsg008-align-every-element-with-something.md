---
id: DSG008
title: Align every element with something
applies-when: Positioning elements in a layout.
---

## Rule

Elements should participate in a visible alignment system so their relationships are clear.

## Check

* Each element should align logically to another element, container edge, baseline, grid line, or established layout axis.
* Flag isolated offsets that do not belong to the layout system.
