---
id: DSG031
title: Keep visual treatment focused on the task
applies-when: Adding decoration, motion, branding, information, or controls around a primary user task.
---

## Rule

Remove visual work that distracts from the task without adding useful meaning.

## Check

* Check whether each prominent element supports content, action, orientation, or the stated expressive purpose.
* Prefer a simpler treatment when it communicates the same result.
* Retain necessary instructions, status, accessibility cues, and user choice; fewer visible elements are not automatically better.

## Exceptions

An expressive brand or editorial brief may justify prominent visual work. Judge it against that purpose rather than imposing neutral styling.
