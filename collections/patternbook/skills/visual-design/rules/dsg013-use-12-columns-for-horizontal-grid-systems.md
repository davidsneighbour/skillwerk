---
id: DSG013
title: Use 12 columns for horizontal grid systems
applies-when: Defining a horizontal column grid.
---

## Rule

When a layout uses a conventional column grid, default to 12 columns.

## Check

* Use a 12-column base unless the project design system specifies another grid.
* The grid should support clean division into common 1-, 2-, 3-, and 4-column layouts.
