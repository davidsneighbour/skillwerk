# Shared vocabulary

In this document, preferred terms and aliases are used interchangeably.

preferred term: project
aliases: this project, this repository
meaning: The repository that the current task concerns. Both phrases refer to the same scope.

preferred term: project root
aliases: repository root, root directory
meaning: The top-level directory of that repository.

preferred term: skill
aliases: -
meaning: One independently loadable capability with a `SKILL.md` entry point.

preferred term: collection
aliases: -
meaning: A named group of skills, such as Clerkwork.
