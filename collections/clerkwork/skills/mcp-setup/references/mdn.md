# MDN

Use the [official MDN MCP guide](https://developer.mozilla.org/en-US/mcp) for current setup, service availability, and data handling. The remote HTTP endpoint is `https://mcp.mdn.mozilla.net/`. Recheck it before configuration. Do not install a local npm server for this remote setup.

Read the guide's client-specific links and the installed client's help to choose the configuration schema and scope. A useful verification is MCP tool discovery; a documentation query is optional and should use a public web-platform topic without private project content.
