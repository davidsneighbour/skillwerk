# Clean notes

Create clean notes only when explicitly requested after an interrogation run.

Clean notes represent the knowledge layer.

They are not:

* another summary;
* a shorter transcription;
* a record of the analysis process;
* a list of everything the source said.

They contain only what survived interrogation and is worth retaining.

## Include

* durable principles;
* corrected definitions;
* useful distinctions;
* validated or defensible mechanisms;
* decision logic;
* constraints;
* trade-offs;
* failure conditions;
* reusable frameworks;
* unresolved questions worth retaining.

## Exclude

* source-specific marketing;
* engagement bait;
* authority signalling;
* transcription artefacts;
* rejected claims;
* disproven assumptions;
* redundant examples;
* critique that is no longer necessary to understand the retained knowledge.

## Requirement

The notes must make sense without access to the original source.

Where uncertainty remains important, preserve it rather than converting it into
a definitive statement.

Do not preserve the source's terminology merely because the source used it.
Prefer clear functional terminology unless the original term is itself useful.

## Relationship to reusable prompts

Reusable prompts and clean notes serve different purposes.

A reusable prompt captures a method that can be applied again.

Clean notes capture knowledge worth retaining from this particular analysis.

Include both only when both contain independent value.
